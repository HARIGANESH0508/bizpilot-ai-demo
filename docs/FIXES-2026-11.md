# BizPilot AI reliability fixes — 18 Nov 2026

## Changes
1. `reanalyze()` now validates the current reviewed invoice fields rather than clearing OCR text and overwriting corrections. `reprocess_source()` is the explicit operation for discarding corrections and re-reading the original file.
2. Three-way matching aggregates invoice quantities by matched PO item before comparing cumulative approved + current quantities against ordered and received quantities.
3. Price variance is checked in both directions (above and below PO price).
4. Dashboard labels the parser score as a heuristic extraction indicator, not a calibrated probability.
5. Added regression tests for manual correction preservation, duplicate invoice line aggregation and below-PO price variance.
